# Alpha Lab: project instructions

## Git workflow
- Commit after each logical change, with clear messages.
- Before every commit: run tests; check `git status` for secrets, .env files, data or large files; never commit them.
- Push to GitHub at the end of every phase, and whenever I ask.
- Never force-push, rewrite history, or delete branches without asking me first.
- If CI fails after a push, fix it before starting new work.
